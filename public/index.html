XML lcdBacklight—

与 RGB Gamma LUT 分开调用，不把这个值乘进像素。DIVA OLED 没有 LCD 背光；这个字段仍用于面板亮度控制。

UltVMQ：SetBrightness(fullScaleLumens × value)。DIVA USB 接口接收 nits，通常使用默认 250。下方 DDC/CI 试用是通用替代路径，百分比不等于 nits，不是 DIVA USB API。

每通道 256 项连成曲线；移动下方索引可查看对应点。

        
        

        
坐标说明 / 全部 256 项数据
          
横轴：输入通道码值 0–255。纵轴：送入 Gamma API 的 16 位输出 0–65535。每个通道的 256 项数据连成曲线，图表适应面板宽度，无需滚动。重合曲线用不同线宽区分，当前查表索引用 R 大、G 中、B 小的同心点标出。连线仅辅助阅读，不改变实际查表数据。没有按本表最大值重新归一化。

          
橙色水平虚线是当前 Ambient 的 lcdBacklight，读取独立右轴 0–100%。它对所有灰阶使用同一个面板亮度设置，并不是第四条 Gamma LUT。RGB 和 lcdBacklight 一起被选中，但仍走不同硬件接口；此处百分比不是测量的亮度或 nits。

实现依据与边界

        
    
          
  • ldsFileReader.cpp：读取 RGB 行，每项左移一位；主屏与触屏均如此。
    • 
          
  • ldsmain.cpp：index = Ambient + Tint × AmbientCount + BlackLevel × AmbientCount × TintCount（全部零基）。
    • 
          
  • fcsdf.cpp：组装 GAMMARAMP 并按主屏 / 触屏的 Intel UID 调用 SetGammaRamp。
    • 
          
  • fcLcdBacklight.cpp / HwDevDivaDisplayUtlImpl.cpp：独立面板亮度、nits 与 USB 命令，不是 RGB Gamma。
    • 
          
  • 本工具使用 XML 中 Active*Indexes 校验完整维度。原 LDS 使用编译期数量并缓存 XML；本工具按按钮重新读取。
    • 
          
  • 不自动识别哪块屏是 Main / TS，必须手动选择；不实现 SVIO、Protego 非 PWM 补偿或厂商自定义初始化。
